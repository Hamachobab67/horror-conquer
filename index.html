관리자 도구

Google 계정으로 로그인해야 사용할 수 있어.

안내: 영상은 Supabase 공유 데이터베이스에 저장돼. 관리자 권한이 확인된 계정만 추가·수정·삭제할 수 있어. 설정이 완료되기 전에는 저장 작업을 진행하지 마.
유튜브 링크 입력 후 영상 정보를 자동 조회할 수 있어. API 키가 없으면 직접 입력해 줘.

항목별 평가 (0~5점, 0.5점 단위)

키는 이 브라우저에만 저장돼. 공식 API를 사용하려면 Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 발급받아야 해. 키를 HTML 파일에 직접 적어 GitHub에 올리지는 마.

유튜브 링크를 입력하면 썸네일이 자동 표시돼. API 키를 설정하면 제목·영상 길이·업로드 날짜·설명을 조회할 수 있어. 자동 조회가 실패해도 모든 항목은 직접 입력하거나 수정할 수 있어.

HOW TO USE

이용 가이드

공포 요소와 평가 점수를 살펴보고, 지금의 나에게 맞는 영상을 골라보세요.

이 사이트는 이렇게 이용해요

  1. 영상 카드에서 제목과 게임 이름, 등록된 공포 요소 평가를 확인해요.
  2. 카드를 누르면 상세 정보와 평가 기준별 점수를 볼 수 있어요.
  3. 검색·정렬·공포 요소 필터를 이용해 관심 있는 영상을 찾아보세요.
  4. 평가는 영상의 모든 장면이 똑같이 무섭다는 뜻이 아니라, 영상 속에 등장하는 요소를 미리 살펴보기 위한 참고 정보예요.

평가 점수는 어떻게 읽나요?

중요: 스토리를 제외한 공포 요소 점수는 영상 전체의 평균이 아니라, 영상 안에서 등장하는 가장 강한 장면의 강도를 기준으로 매겨요. 특정 장면의 점수가 높더라도 영상 내내 그 정도로 무서운 것은 아닐 수 있어요.

스토리

이야기의 흥미도와 구성에 대한 평가예요. 다른 공포 요소와 달리 높을수록 긍정적이라는 뜻이에요.

신체 훼손 묘사

피해를 입은 신체나 신체 훼손 장면이 얼마나 강하게 묘사되는지 살펴봐요.

점프 스케어 강도

갑작스러운 등장이나 큰 소리로 놀라게 하는 장면 중 가장 강렬한 장면의 강도를 기준으로 해요. 등장 빈도는 점수에 합치지 않고, 필요한 경우 특이사항에 따로 기록해요.

괴물·귀신 외형 공포도

괴물이나 귀신의 생김새와 등장 장면이 얼마나 위협적이거나 무섭게 느껴질 수 있는지 나타내요.

심리적 긴장·불안

불길한 분위기, 불안감, 심리적으로 압박하는 연출의 강도를 나타내요.

추격·도주 압박감

쫓기거나 도망쳐야 하는 상황에서 느껴지는 긴박함과 압박의 강도를 나타내요.

평가는 운영자가 영상을 보고 기록한 주관적인 참고 정보예요. 사람마다 무섭게 느끼는 요소는 다를 수 있고, 미평가 항목은 아직 점수가 등록되지 않았다는 뜻이에요.

팬이 직접 기록하는 비공식 영상 가이드입니다. 영상 재생은 유튜브 원본 페이지에서 이루어집니다.
